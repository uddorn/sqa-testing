# Документація API книжкового магазину

Цей проект — RESTful API для книжкового магазину, створений за допомогою FastAPI. Він дозволяє керувати інвентарем книг та оформляти замовлення.

## Опис API

### Книги 
- `POST /books/` - Додати нову книгу.
  - Тіло запиту: `{"isbn": "str", "title": "str", "author": "str", "price": "float", "quantity": "int", "description": "str"}`
- `GET /books/` - Отримати список усіх книг.
- `GET /books/{isbn}` - Отримати детальну інформацію про книгу за її ISBN.
- `PUT /books/{isbn}` - Оновити дані книги (можна змінити ціну, кількість, опис).
  - Тіло запиту: `{"price": "float", "quantity": "int", "description": "str"}`
- `DELETE /books/{isbn}` - Видалити книгу з інвентарю.

### Замовлення
- `POST /orders/` - Оформити замовлення.
  - Тіло запиту: `{"customer_id": "int", "items": [{"isbn": "str", "quantity": "int"}]}`
- `GET /orders/{order_id}` - Отримати інформацію про замовлення.
- `PUT /orders/{order_id}/status` - Оновити статус замовлення.
  - Тіло запиту: `{"status": "на обробці" | "відправлено" | "виконано"}`
- `GET /customers/{customer_id}/orders` - Отримати всі замовлення певного клієнта.

## Інструкція для розгортання додатку

1. **Встановіть залежності**:
   Переконайтеся, що у вас встановлено Python, і виконайте команду:
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустіть сервер**:
   Щоб запустити сервер локально, виконайте наступну команду:
   ```bash
   uvicorn app.main:app --reload
   ```
   Після цього API буде доступне за адресою: `http://127.0.0.1:8000`.
   Автоматична документація Swagger UI доступна за адресою: `http://127.0.0.1:8000/docs`.

## Опис процесу запуску тестів

Для перевірки працездатності логіки та API у проекті реалізовано автоматизовані тести з використанням фреймворку `pytest`.

1. Переконайтеся, що встановлено всі залежності з `requirements.txt`.
2. Виконайте в кореневій папці проекту (де знаходиться `pytest.ini`) команду:
   ```bash
   pytest
   ```
3. Щоб отримати детальніший звіт про кожен пройдений тест, скористайтеся прапорцем `-v`:
   ```bash
   pytest -v
   ```
